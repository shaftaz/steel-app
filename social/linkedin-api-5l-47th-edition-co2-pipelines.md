# LinkedIn draft — 47th edition (api-5l-47th-edition-co2-pipelines)

For 102 years, API 5L described pipe for hydrocarbons. As of June 2, it describes pipe for CO₂ too.

The 47th edition: first-ever dedicated CO₂ transmission requirements (because supercritical CO₂ can sustain running ductile fractures natural gas never could), tighter HFW seam controls, updated sour-service testing — 15+ topic areas, with a monogram compliance clock already ticking toward mid-2027.

A standard is a starting gun. CCUS pipe is now a qualified-supply business — and in qualified-supply businesses, early certification IS market share.
